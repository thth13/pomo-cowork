# Pomo Cowork — Pocket Timer

Chrome-расширение работает через аккаунт, без открытой вкладки сайта.
Запуск, пауза, продолжение, остановка/сброс, Pomodoro и Time track,
настройки длительности и выбор задачи из списка аккаунта. Требуется Chrome 120+.

## Установка и вход

1. Обнови сайт/сервер: расширению нужен новый endpoint `/api/timer` и страница
   `/extension/authorize` из этого изменения.
2. Открой `chrome://extensions`, включи **Режим разработчика**, нажми
   **Загрузить распакованное расширение** и выбери папку `chrome-extension`.
   Предыдущую версию с выбором вкладки удали и загрузи эту папку заново:
   теперь у расширения фиксированный ID. Последующие изменения можно обновлять
   кнопкой **Обновить** на его карточке.
3. Открой popup и нажми **Sign in to your account**.
4. В открытой странице войди через обычный аккаунт сайта (email или Google)
   и нажми **Use this account**. Если ты уже авторизован, повторный ввод не нужен.
5. Вернись в popup. Текущий таймер аккаунта появится автоматически.
   Страницу сайта теперь можно закрыть.

По умолчанию сервер — `https://pomo-co.work`. Для разработки перед входом
раскрой **Server address** и введи `http://localhost:3000` (или свой порт).
Также разрешены `https://www.pomo-co.work` и `http://127.0.0.1:PORT`.
Кнопки Connect и выбора вкладки больше нет. Для смены аккаунта или сервера
выйди из аккаунта расширения и войди снова.

## Общий таймер аккаунта

`/api/timer` возвращает авторизованному пользователю его активную/приостановленную
сессию, последнюю завершённую сессию, настройки и время сервера. Расширение
обращается к нему напрямую из фонового service worker. Открытый popup обновляет
состояние каждые 3 секунды; сайт — каждые 5 секунд и при возврате на вкладку.
С закрытым popup расширение обновляет состояние через Chrome alarms каждые
30 секунд и отдельно планирует проверку срока завершения текущей сессии.
Время в popup вычисляется по серверному startedAt с поправкой на часы сервера;
при паузе используются сохранённые remainingSeconds.

Запуск на сайте виден в расширении и наоборот. Текущую сессию можно продолжить,
приостановить или остановить с любой стороны. Сервер проверяет владельца и
версию сессии; устаревшая команда получает конфликт и не меняет более новую
сессию. Создание сериализуется по пользователю и не заменяет незаметно таймер,
который одновременно запустился в другом интерфейсе. Завершение и начисления
используют существующий серверный обработчик с защитой от повторного начисления.

Chrome может задерживать alarms при сне устройства или закрытом браузере.
Состояние сессии остаётся на сервере; после пробуждения/перезапуска или открытия
popup завершение просроченной сессии будет обработано. Постоянно открытый сайт
или popup не требуются; для управления и записи нужна сеть.

Режимы и настройки: focus 1–60 минут, short break 1–30, long break 1–60,
long break after 2–10. Текущий таймер при изменении длительности не перезапускается.
Time track включается переключателем в Timer settings и сохраняет Pro-ограничение
аккаунта и лимит 24 часа. Выход доступен во всплывающем меню по клику на никнейм.
Перед запуском в popup можно выбрать незавершённую задачу аккаунта. Список
обновляется каждые 15 секунд; пустой список скрыт. Новая сессия из расширения
создаётся в общем пространстве без проекта/комнаты. Уже запущенная на сайте
сессия сохраняет свою задачу, проект и комнату при управлении из расширения.
Задача отображается только в поле выбора, без дублирования внутри дисплея таймера.
Выбор сохраняется для аккаунта после окончания сессии и повторного открытия popup;
удалённые и выполненные задачи убираются при обновлении списка. Во время работы
доступны Pause и Stop, на паузе — Resume и Stop.
Автоматический запуск следующей сессии остаётся функцией сайта; расширение
предлагает следующий режим, но не начинает следующую сессию само.

Popup поддерживает English/Español и сохраняет язык, выбранный при входе.
Черновик настроек не затирается фоновыми обновлениями; закрытие popup его сбрасывает.
При недоступной сети controls блокируются до свежей синхронизации. Команды с
неопределённым результатом не повторяются автоматически. **Sign out** удаляет
авторизацию расширения и его фоновое расписание, но не останавливает серверную
сессию и не выходит из аккаунта сайта.

## Авторизация и хранение

Расширение — собственный клиент Pomo Co и использует существующий JWT аккаунта
с теми же правами, что и сайт. Передача происходит только после явного нажатия
**Use this account**, через `runtime.sendMessage`; токен не передаётся в URL.
Фоновый процесс принимает ответ только от разрешённого origin, страницы
`/extension/authorize`, ожидаемой вкладки и случайного requestId с 10-минутным
сроком. Затем проверяет JWT на сервере.
Страница авторизации передаёт токен только фиксированному ID нашего расширения
из `lib/extensionIdentity.ts`, соответствующему публичному `key` в manifest.
Изменение публичного ключа требует обновления этого ID и повторной установки.

JWT хранится в `chrome.storage.local` только в профиле этого Chrome, без sync.
`setAccessLevel(TRUSTED_CONTEXTS)` закрывает доступ со стороны content scripts;
content scripts у этой версии отсутствуют. При выходе или HTTP 401 токен удаляется.
Пароли, cookies и история сессий не копируются. Текущий снимок таймера и запрос
входа живут в `chrome.storage.session`, очищаются при выходе и перезапуске браузера.
Клиент хранит адрес сервера, язык и предпочтение следующего режима отдельно по
серверу/аккаунту; расширение не читает localStorage сайта.

## Оформление и проверка

`app/globals.css` — источник палитры. Сгенерированный `tokens.css` используется
popup и badge. Обновить цвета после изменения сайта:

```sh
npm run extension:tokens
```

Сборка и npm install не нужны. Все скрипты и стили локальные.
Сборки, запуск приложения, tsc и runtime-тесты при реализации не запускались.
ESLint изменённых TypeScript-файлов, `node --check` для JavaScript и
`git diff --check` прошли. Общий UI-аудит сохранил прежнее замечание про native
select в `app/stats/page.tsx:793`; этот экран не изменялся.
Ручные проверки: email/Google вход; уже активный и paused таймер аккаунта;
запуск/пауза/продолжение/остановка с обеих сторон; закрытый сайт и popup;
перезапуск Chrome; окончание таймера и отсутствие двойных начислений;
одновременный запуск из двух интерфейсов; settings; Time track с Pro/без Pro;
потеря сети; истечение авторизации; смена аккаунта/сервера.
